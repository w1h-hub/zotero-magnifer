# Zotero Magnifier · 框选放大镜

适用于 Zotero 10.0.x 的 PDF 框选放大插件。当前版本 **0.3.2**，已由使用者在 Zotero 10.0.6 中确认可用。

## 功能

- 拖动鼠标框选 PDF 单页内的任意矩形区域，在浮动窗口中查看。
- 独立桌面窗口可移出 Zotero；图像随窗口等比例缩放，始终完整显示选区，不受主页面缩放影响。
- 从原始 PDF 重新渲染选区，保留矢量文字与图形的清晰度。
- 开启框选时切换为手型工具，拦截文字选择；退出时恢复原工具。
- 拖动窗口边缘自由调整大小；调整结束后从 PDF 重新高清渲染。

## 安装

下载仓库中的 `zotero-magnifier-0.3.2.xpi`。在 Zotero 的「工具 → 插件」中点击齿轮，选择「从文件安装插件」，安装下载的文件，然后重启 Zotero。

## 使用

1. 打开 PDF，点击工具栏的「框选放大」。
2. 按住鼠标左键拖出矩形，松开后显示预览。
3. 点击「− / ＋」或按住 **Alt** 滚动鼠标滚轮调整窗口大小，图像随之缩放。预览显示实际倍率。
4. 拖动系统标题栏移动窗口，拖动边缘或四角调整大小；图像等比例适应窗口，可完整查看，无需滚动。
5. 在页面重新拖动可更换选区。「×」关闭预览，**Esc** 退出框选模式，**Alt+M** 切换模式。

## 限制

- 一次选择位于一页内，不能跨页；旋转页面后请重新框选。
- 高清预览显示 PDF 原始内容，不叠加 Zotero 的高亮和批注。
- 扫描图片的清晰度取决于原图；超大选区受渲染像素上限约束。
- 深色模式下，预览使用白底原始 PDF 色彩。
- 此版本使用 Zotero 内部 PDF.js 接口，未来版本升级可能需要适配。
- 暂无在线更新服务。清单中的 `.invalid` 地址为保留域名，不提供自动更新；请手动安装新版本，可在插件详情中关闭自动更新。

## 开发

`bootstrap.js` 包含工具栏、框选、窗口与 PDF 渲染逻辑；`manifest.json` 包含插件名称、版本及兼容范围；`content/preview.xhtml` 为原生独立窗口。无第三方依赖。

修改后将 `bootstrap.js`、`manifest.json` 和 `content/` 文件夹放在 ZIP 根目录，扩展名改为 `.xpi`，重新安装并重启 Zotero。

## 验证
