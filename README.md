# Zotero Magnifier · 框选放大镜

适用于 Zotero 10.0.x 的 PDF 框选放大插件。当前版本 **0.2.3**，已由使用者在 Zotero 10.0.6 中确认可用。

## 功能

- 拖动鼠标框选 PDF 单页内的任意矩形区域，在浮动窗口中查看。
- 预览采用独立的 **100%–800%** 缩放，默认 **200%**，不受主页面缩放影响，适合分屏阅读。
- 从原始 PDF 重新渲染选区，保留矢量文字与图形的清晰度。
- 开启框选时切换为手型工具，拦截文字选择；退出时恢复原工具。
- 可移动预览窗口，切换窗口大小，滚动查看大型选区。

## 安装

下载仓库中的 `zotero-magnifier-0.2.3.xpi`。在 Zotero 的「工具 → 插件」中点击齿轮，选择「从文件安装插件」，安装下载的文件，然后重启 Zotero。

## 使用

1. 打开 PDF，点击工具栏的「框选放大」。
2. 按住鼠标左键拖出矩形，松开后显示预览。
3. 点击「− / ＋」或按住 **Alt** 滚动鼠标滚轮调整独立倍率。
4. 点击「窗口：小 / 中 / 大」切换窗口宽度。拖动标题栏移动预览窗口。
5. 在页面重新拖动可更换选区。「×」关闭预览，**Esc** 退出框选模式，**Alt+M** 切换模式。

## 限制

- 一次选择位于一页内，不能跨页；旋转页面后请重新框选。
- 高清预览显示 PDF 原始内容，不叠加 Zotero 的高亮和批注。
- 扫描图片的清晰度取决于原图；超大选区受渲染像素上限约束。
- 深色模式下，预览使用白底原始 PDF 色彩。
- 此版本使用 Zotero 内部 PDF.js 接口，未来版本升级可能需要适配。
- 暂无在线更新服务。清单中的 `.invalid` 地址为保留域名，不提供自动更新；请手动安装新版本，可在插件详情中关闭自动更新。

## 开发

`bootstrap.js` 包含工具栏、框选、窗口与 PDF 渲染逻辑；`manifest.json` 包含插件名称、版本及兼容范围。无第三方依赖。

修改后将 `bootstrap.js` 与 `manifest.json` 放在 ZIP 根目录，扩展名改为 `.xpi`，重新安装并重启 Zotero。

## 验证

0.2.3 已由使用者实机确认。开发时也通过语法检查，以及鼠标框选流程、页对象回退读取、独立倍率渲染、工具恢复与异步取消的模拟测试。其他系统与 Zotero 版本尚未验证。
